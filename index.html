使用说明与资料边界

本文件是 steel_sales_email_templates.md 的产品级配套手册。每个产品均采用独立的报价判断逻辑，模板正文为英文，诊断与使用说明为中文。

  • “报价必须知道的信息”指形成准确、可执行报价所需的字段；第一封邮件仍应优先只问其中最关键的 2-4 组，并把可以后置的信息留到第二轮。
  • 客户提供 drawing、MTO、datasheet 或 item list 后，必须先阅读资料，不能重复询问文件中已经明确的信息。
  • 公司目录明确展示 Stainless Steel Plate、Stainless Steel Bar、Seamless/Welded Pipe、Butt-weld Fittings、Flanges 和 High Pressure Fittings。Carbon/Alloy Steel Plate 与 Bar 的具体 grade、尺寸范围、标准、交货状态和供货能力未在目录中详细列出，因此相关模板只使用变量，报价前须内部确认。
  • 未确认的库存、产能、价格、交期、证书、测试、项目经验或替代材质不得写成事实。
  • 所有技术替代只能作为“供客户工程团队审批的选项”，不得由销售人员自行变更。

产品专用变量

变量含义
[THICKNESS] [WIDTH] [LENGTH]板材厚度、宽度和长度；必须带单位
[SURFACE/FINISH]不锈钢表面或其他明确表面要求
[DELIVERY CONDITION]轧制、正火、调质、固溶等客户指定交货/热处理状态；按正式规格填写
[DIAMETER] [PROFILE]棒材直径或截面形式及尺寸
[OD/NPS] [WT/SCHEDULE]管材外径/公称尺寸及壁厚/Schedule
[WELDING PROCESS]客户标准要求的焊管制造/焊接方式
[DEGREE] [RADIUS]弯头角度与 LR/SR/指定半径
[RUN SIZE] [BRANCH SIZE]三通主管与支管尺寸
[LARGE SIZE] [SMALL SIZE]大小头两端尺寸
[FLANGE TYPE] [FACING]法兰类型及密封面
[CLASS/PN]压力等级体系；必须与标准配套
[END CONNECTION] [THREAD STANDARD]高压管件或管材端部连接与螺纹标准
01

Stainless Steel Plate

A报价必须知道的信息
  1. Grade/material specification。
  2. Product standard；若客户只按商业牌号采购，至少确认 grade 和允许的标准体系。
  3. Thickness × width × length。
  4. Quantity：pieces 或 total weight。
  5. Surface/finish；不锈钢表面会直接影响工艺和价格。
  6. 对价格有强制影响的 tolerance、testing 或 certificate 要求（如项目已规定）。

第一轮优先顺序： [GRADE]/[STANDARD] | [THICKNESS] × [WIDTH] × [LENGTH] | [SURFACE/FINISH] | [QUANTITY]。

B可选确认的信息
  • Thickness/width/length tolerance、flatness。
  • Edge condition、cut-to-size、protective film/paper。
  • Heat treatment/solution condition（如规格要求）。
  • PMI、UT、mechanical/corrosion test、MTC 或第三方检验要求。
  • Packing、marking、destination、Incoterm、分批交付。
C不应该第一次就问的问题
  • 详细包装唛头、每包片数和托盘结构。
  • 客户完整加工图、焊接工艺或最终设备全部设计数据。
  • 在 grade、尺寸和数量未知时询问完整收货地址。
  • 标准已规定时再次要求客户逐项填写化学成分。
  • 未确认项目性质时一次索要所有测试、证书和检验机构信息。

Stainless Steel Round Bar

A报价必须知道的信息
  1. Grade and standard。
  2. Diameter × length；若为定尺、倍尺或随机长度，应明确表达。
  3. Quantity：pieces 或 total weight。
  4. Supply condition/surface：如 hot-rolled、peeled/turned、cold-finished、ground/polished 等，按客户实际规格填写。
  5. Diameter tolerance；精密棒材或后续加工有要求时必须确认。

第一轮优先顺序： [GRADE]/[STANDARD] | [DIAMETER] × [LENGTH] | [SURFACE CONDITION] | [QUANTITY]。

  • Diameter tolerance、straightness、ovality。
  • Heat-treatment/solution condition。
  • End condition、chamfer、saw cut、machining allowance。
  • PMI、UT、mechanical test、MTC、third-party inspection。
  • Surface roughness、protective packing、marking、destination、Incoterm。
C不应该第一次就问的问题
  • Pipe Schedule、wall thickness、flange class 或 PN。
  • 客户最终零件全部机加工尺寸；原材料报价只需确认毛坯要求。
  • 详细包装层数、端帽、托盘或防锈周期。
  • 标准已明确时逐项追问常规化学成分。
  • 在直径、长度和数量未知时先索要完整收货地址。

Cross-product Final Check / 跨产品防混用检查

  1. Plate 必须围绕 grade + thickness × width × length + quantity，不使用 Schedule、Class/PN 或 LR/SR。
  2. Bar 必须围绕 grade + diameter/profile × length + condition + quantity，不使用 pipe wall 或 flange facing。
  3. Pipe 必须确认 OD/NPS + WT/Schedule + length + quantity；seamless 不问焊缝，welded 才确认 welding process/seam/test。
  4. Elbow 必须确认 degree + radius；Tee 必须确认 run + branch；Reducer 必须确认 CON/ECC + large end + small end。
  5. Flange 必须确认 standard + type + size + Class/PN + facing，并只在适用类型询问 bore/Schedule。
  6. High Pressure Fittings 必须确认 fitting type + pressure rating + end connection/thread，不能默认 NPT，也不能直接套用 butt-weld fitting 的 Schedule/LR/SR 逻辑。
  7. 所有模板发送前必须删除未使用变量，只保留一个主要 CTA，并核对附件、正文和报价单中的规格一致。
